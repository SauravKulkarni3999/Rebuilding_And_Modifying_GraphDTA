## Overview

GraphDTA-3D extends the original [GraphDTA](https://academic.oup.com/bioinformatics/article/37/8/1140/5942970) architecture by replacing 1D protein sequence encoders with **AlphaFold-derived residue graphs** — Cα proximity graphs at an 8Å distance threshold. This gives the model direct access to 3D structural topology rather than relying on sequence order alone.

The core hypothesis — that structural context improves binding affinity prediction — is motivated directly by the [AMP Benchmark](https://github.com/SauravKulkarni3999/AMP-Activity-Toxicity-Baseline-Benchmark) study, which proved that 3D biophysical features outperform 1D sequence models across antimicrobial peptide tasks.

Both models (GraphDTA baseline and GraphDTA-3D) are implemented and benchmarked here for direct comparison.

## Architecture

### GraphDTA (Baseline)
- **Drug encoder:** 3-layer GCN on molecular graphs (SMILES → RDKit atom features, 83-dim)
- **Protein encoder:** 1D CNN on tokenized amino acid sequences (max length 1000)
- **Fusion:** Concatenated embeddings → 2-layer MLP → affinity scalar

### GraphDTA-3D
- **Drug encoder:** 3-layer GCN on molecular graphs (identical to baseline)
- **Protein encoder:** 3-layer GCN on **AlphaFold Cα residue graphs** (8Å distance threshold, 20-dim one-hot AA features)
- **Fusion:** Concatenated embeddings → 2-layer MLP → affinity scalar

The only architectural difference is the protein encoder — everything else is held constant for a clean comparison.

## Quickstart

### Installation

```bash
git clone https://github.com/SauravKulkarni3999/GraphDTA-3D
cd GraphDTA-3D

# Option A — Conda (recommended)
conda env create -f environment.yml
conda activate graphdta3d_env

# Option B — pip
pip install -r requirements.txt
```

> **Note on PyTorch Geometric:** `requirements.txt` pins PyG dependencies against PyTorch 2.0.1 + CUDA 11.8. If your environment differs, install PyTorch first, then follow the [official PyG installation guide](https://pytorch-geometric.readthedocs.io/en/latest/install/installation.html) for matching versions.

---

### Step 1 — Download Raw Data

**Davis and KIBA datasets** (from DeepDTA):
```bash
# Place contents in ./data/davis/ and ./data/kiba/ respectively
# Source: https://github.com/hkmztrk/DeepDTA/tree/master/data
# Required files per dataset: ligands_can.txt, proteins.txt, Y, folds/
```

Each dataset directory also needs helper CSVs (see repo wiki for generation scripts):
- `data/davis/` → `drugs.csv`, `proteins.csv`, `drug_protein_affinity.csv`, `davis_proteins.fasta`
- `data/kiba/` → `kiba_affinity_df.csv`, `kiba_proteins.fasta`

**UniProt Swiss-Prot FASTA** (for protein→UniProt ID mapping):
```bash
mkdir -p data/external
wget -O data/external/uniprot_sprot.fasta.gz \
  https://ftp.uniprot.org/pub/databases/uniprot/current_release/knowledgebase/complete/uniprot_sprot.fasta.gz
gunzip data/external/uniprot_sprot.fasta.gz
```

---

### Step 2 — Preprocess

Run all preprocessing scripts from the repository root. Activate your conda environment first.

**Drug graphs (both datasets):**
```bash
python src/preprocessing/process_drug_graphs.py \
  --dataset_name davis --csv_path ./data/davis/drugs.csv \
  --smiles_col Canonical_SMILES --drug_id_col Drug_Index \
  --output_dir ./data/processed/davis

python src/preprocessing/process_drug_graphs.py \
  --dataset_name kiba --csv_path ./data/kiba/kiba_affinity_df.csv \
  --smiles_col SMILES --drug_id_col Drug_Index \
  --output_dir ./data/processed/kiba
```

**Protein sequences (for GraphDTA baseline):**
```bash
python src/preprocessing/process_protein_sequences.py \
  --dataset_name davis --csv_path ./data/davis/proteins.csv \
  --sequence_col Sequence --protein_id_col Protein_Index \
  --output_dir ./data/processed/davis

python src/preprocessing/process_protein_sequences.py \
  --dataset_name kiba --csv_path ./data/kiba/kiba_affinity_df.csv \
  --sequence_col Sequence --protein_id_col Protein_Index \
  --output_dir ./data/processed/kiba
```

**Protein 3D structure graphs (for GraphDTA-3D):**
```bash
# 1. Map sequences to UniProt IDs
python src/preprocessing/map_proteins_to_uniprot.py \
  --query_fasta ./data/davis/davis_proteins.fasta \
  --uniprot_fasta ./data/external/uniprot_sprot.fasta \
  --output_csv ./data/processed/davis/davis_uniprot_mapping.csv

# 2. Download AlphaFold PDB structures
python src/preprocessing/download_pdb_structures.py \
  --mapping_csv ./data/processed/davis/davis_uniprot_mapping.csv \
  --pdb_dir ./data/davis/pdb_files

# 3. Build Cα residue graphs from PDBs
python src/preprocessing/generate_protein_graphs.py \
  --pdb_dir ./data/davis/pdb_files \
  --output_path ./data/processed/davis/davis_protein_graphs.pt
```

Repeat steps 1–3 for KIBA by substituting `davis` → `kiba` in the paths above.

---

### Step 3 — Train

**GraphDTA-3D on Davis:**
```bash
python src/train_model.py \
  --dataset_name davis \
  --model_architecture GraphDTA3D \
  --epochs 500 \
  --batch_size 512 \
  --learning_rate 0.0005 \
  --dropout_rate 0.3 \
  --output_dir ./training_runs/GraphDTA3D_Davis
```

**GraphDTA baseline on Davis:**
```bash
python src/train_model.py \
  --dataset_name davis \
  --model_architecture GraphDTA \
  --epochs 500 \
  --batch_size 512 \
  --learning_rate 0.0005 \
  --dropout_rate 0.2 \
  --output_dir ./training_runs/GraphDTA_Davis
```

Substitute `--dataset_name kiba` and adjust `--affinity_file`/`--affinity_col_name` for KIBA. The script saves the best model checkpoint (by validation CI) and a results JSON to `--output_dir`.

---

### Step 4 — Predict on New Inputs

```bash
# GraphDTA-3D (requires AlphaFold PDB for the target protein)
python demo_predict.py \
  --model_architecture GraphDTA3D \
  --model_weights_path ./weights/graphdta3d_davis.pt \
  --smiles "CC1=C2C=C(C=CC2=NN1)C3=CC(=CN=C3)OCC(CC4=CC=CC=C4)N" \
  --protein_pdb_path ./data/davis/pdb_files/Protein_0.pdb \
  --dropout_rate 0.3

# GraphDTA baseline (requires raw protein sequence)
python demo_predict.py \
  --model_architecture GraphDTA \
  --model_weights_path ./weights/graphdta_davis_baseline_best_model.pt \
  --smiles "CC1=C2C=C(C=CC2=NN1)C3=CC(=CN=C3)OCC(CC4=CC=CC=C4)N" \
  --protein_sequence "MKKFFDSRREQGGSGLGSGSSGGGGSTSGL..." \
  --dropout_rate 0.2
```

## Design Decisions & Honest Reporting

**What was held constant:** Drug encoder architecture, MLP fusion layers, optimizer (Adam, lr=0.0005), batch size (512), split ratios (80/10/10), early stopping criterion (validation CI), and random seed (42). The only variable between the two models is the protein encoder.

**What was not done:** No hyperparameter search, no ensembling, no dataset-specific tuning. The results reflect a single training run per model per dataset.

**Known limitation:** AlphaFold coverage is incomplete — proteins without a UniProt mapping are excluded from GraphDTA-3D training, which slightly reduces the dataset size relative to the baseline. This is logged during preprocessing.
